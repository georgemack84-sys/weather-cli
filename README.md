\# Weather CLI



A lightweight command-line weather application powered by Open-Meteo.



Weather CLI provides current conditions, multi-day forecasts, configurable defaults, metric and imperial units, local caching, logging, and a Rich-powered terminal interface.



\## Features



\- Current weather conditions

\- Multi-day forecasts

\- Metric and imperial units

\- Multi-word city names

\- Location disambiguation when multiple matches are found

\- Configurable default city

\- Configurable default forecast length

\- Configurable unit preference

\- Local weather caching

\- Local logging

\- `weather --version`

\- Python 3.10 through 3.13 support

\- Automated tests and CI validation



\## Requirements



Weather CLI requires:



\- Python 3.10 or newer

\- Internet access for weather requests



Supported Python versions:



\- Python 3.10

\- Python 3.11

\- Python 3.12

\- Python 3.13
